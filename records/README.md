# Task records

> **Active 3.3.0 guidance.** Task records prevent duplicate work and preserve acceptance evidence.

## Policy

- One record per task ID.
- Keep the handoff, decision, validation, cost, and outcome linked.
- Record what actually happened, not the full conversation.
- Mark sensitive fields and redact personal data.
- Close or archive abandoned tasks.
- Set a review date for durable outcomes.

Use [../templates/task-record.md](../templates/task-record.md) and [../templates/task-handoff.md](../templates/task-handoff.md).

## Naming

    NRP-<project>-<yyyymmdd>-<seq>.md

Examples:

    NRP-ORIENT-20261103-01.md
    NRP-XHS-20261103-01.md
    NRP-GEO-20261103-01.md

These are examples, not records of executed production work.
