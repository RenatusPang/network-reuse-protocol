# Decisions

> **DRAFT / NOT ACTIVE.** This directory holds decision records for the protocol and, after adoption, for a project.

## Policy

- One decision per file.
- Name: `yyyy-mm-dd-short-slug.md`.
- Link the task, evidence, and validation report.
- Record the gates and the decision-changing reason.
- Include rollback or exit and a review date.
- Supersede an old record; do not create a parallel truth.
- Do not record trivial choices.

Use [../templates/decision-record.md](../templates/decision-record.md).
