# Templates

> **Active 3.2.0 guidance.** Copy a template only when it reduces work. The protocol never creates project files automatically.

| Template | Use when | Output |
| --- | --- | --- |
| [task-handoff.md](task-handoff.md) | work crosses agents or needs independent review | one handoff with ten fields |
| [resource-inventory.md](resource-inventory.md) | before installing or enabling a tool | short inventory and duplicate check |
| [cost-ledger.md](cost-ledger.md) | tokens, APIs, paid tools, or multiple agents are involved | measured and estimated cost rows |
| [validation-report.md](validation-report.md) | a result is about to be claimed | L1–L4 evidence and limits |
| [reuse-radar.md](reuse-radar.md) | a reusable choice should survive the task | radar entry with review date |
| [decision-record.md](decision-record.md) | a durable or high-risk choice needs a rationale | decision record |
| [task-record.md](task-record.md) | audit, handoff, or duplicate prevention | task timeline and outcome |

## Rules

- Replace placeholders; do not leave `<...>` in a finished record.
- Keep one decision per record.
- Link evidence; do not paste whole pages.
- Never put credentials, cookies, or personal data in a template instance.
- Keep the record short enough to be read.
- Mark estimates as estimates.
- Set a review date for every durable entry.
